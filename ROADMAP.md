# Project Roadmap

## Immediate credibility fixes

- Fix broken links, typos, stale wording, and non-portable wiki-style links.
- Align README and portfolio wording with actual repository contents.
- Add a clear maturity/status statement.
- Add a static landing page for GitHub Pages.

## Phase 1 - Methodology hardening

- Expand the analytics decision gate.
- Add data governance, confidentiality, and reproducibility guidance.
- Add evidence-strength guidance to distinguish planning leads from reportable audit findings.
- Add reusable templates for data requirements, data quality, analysis logs, and finding/evidence mapping.

## Phase 2 - Worked examples

- Build at least one end-to-end synthetic example.
- Start with high-value transaction approval testing.
- Add synthetic data, Python notebook/script, output table, visualization, interpretation, and limitations.

## Phase 3 - Website polish

- Enable GitHub Pages from the repository root.
- Use the landing page as the primary external link.
- Keep GitHub as the source repository and template/example library.
- Update the main busera.github.io profile link and wording after Pages is live.

## Phase 4 - Portfolio-grade release

- Add CI checks for link integrity and examples.
- Add screenshots or rendered outputs.
- Add more audit areas: expense reports, logical access, inventory, purchase-to-pay, and change management.
- Add a release tag once the first reproducible example is complete.
